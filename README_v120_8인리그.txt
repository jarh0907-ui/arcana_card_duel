[8인 경쟁 모드]
참가자 8명: 플레이어 1명, AI 7명. 글로벌 HP 100.
각 스테이지 7라운드: 전투 / 전투 / 전투 / 상점 / 전투 / 전투 / 상점.
전투는 1대1로 진행. 패배 시 글로벌 HP -= (스테이지 * 3 + floor(승자 남은 전투 HP / 2)).
전투 자체의 플레이어 시작 체력은 20. 매 경기는 별도로 초기화.
0 이하 탈락. 먼저 탈락한 라운드가 무조건 아래 순위이며, 같은 라운드라면
최종 글로벌 HP가 더 낮은 쪽이 아래, 그래도 같다면 논리적인 전투 종료 시점이 빠른 쪽이 아래.
관전 중 실제 플레이 시간이나 숫자 엔진의 컴퓨터 처리 완료 순서는 순위에 영향을 주지 않음.
미소진 재대결 회피 로테이션 / 홀수 생존 시 부전승 번갈아 배정.

[골드 정산]
매 라운드 +5 (상점 라운드 포함). 승리 +1, 패배 기본 승리보너스 없음.
연승 2회부터 +1 / 4회부터 +2 / 6회부터 +3.
연패 2회부터 +1 / 3회부터 +2 / 5회부터 +3.
이자: 정산 직전 보유 10골드당 +1, 최대 +5. 상점은 연승·연패를 끊지 않음.

[상점: 임시 테스트 수치]
상점 품목 카드 구매 = max(5, (마나 코스트 + 1) * 3) 골드.
카드 제거 = 6골드 (최소 덱 12장 유지).
카드 한 종류 공격력 +1 강화 = 12골드, 최대체력 +2 강화 = 10골드.
내 모든 유닛에 공격력 +1 버프 = 28골드, 최대체력 +1 버프 = 22골드.
구매 / 강화 / 버프는 향후 전투에서 유지. 골드 상한은 아직 설정하지 않음.
이 수치 및 구체적인 상품 등장 방식은 사용자가 아직 결정하지 않은 부분이므로 임시값입니다.

[다른 AI 경기 관전]
AI 대 AI는 프레임·이펙트 없는 숫자 전투를 실행한 뒤 상태 스냅샷만 기록합니다.
관전에서는 턴별 및 단계별 전장을 재생하며 이전/다음/재생/정지/4배속/시점 이동 지원.
AI의 전략 계산을 관전 중 다시 실행하지 않음. 최근 8라운드의 관전 기록만 메모리에 유지하여 저사양 최적화.
게임 새로고침 후에는 리그 진행도와 참가자 덱·골드 등을 로컬 저장에서 복원할 수 있지만
메모리 절약을 위해 관전 스냅샷은 로컬에 영구 저장하지 않습니다.

[추후 결정 사항]
증강체 미구현 (요청대로 보류).
상점 가격, 강화 한도, 버프의 상세 조건은 공식 확정 전.
라운드 사이 챔피언 각성 진행도는 현재 매 경기 초기화 (정식 지속 규칙 미확정).
숫자 엔진은 별도 경량 모델이므로 실제 시각 전투와 아주 복잡한 특수 카드 조합에서 다소 차이가 있을 수 있습니다.
