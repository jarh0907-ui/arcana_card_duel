아르카나 카드 듀얼 v1.2.1 — 왼쪽 글로벌 HP/선수 관전 바

설치: v1.2.0 게임 폴더가 있는 위치에 압축을 풀고 덮어씁니다.
수정 파일: arcana_card_duel/index.html, arcana_card_duel/league_v114.js

- 8인 리그에서 참가자 8명의 글로벌 HP(100 기준)를 왼쪽에 막대 형태로 표시
- 순위, 이름, 탈락 상태를 함께 표시
- 참가자 바 클릭 시 현재 진행된 AI 경기, 없으면 최근 저장된 관전 기록 재생
- 기존 기록이 없는 경우 클릭 시 안내 표시
- 직접 플레이하는 전투 중에도 왼쪽 바 표시 / 다른 AI의 경기 관전 후 내 전투로 복귀
- 작은 화면에서 사이드바 접기/펼치기 버튼 제공
- 1대1 모드에는 사이드바가 나타나지 않음

주의: v1.2.0의 경량 관전 방식과 동일하게 리그 재시작/새로고침으로 사라진 예전 관전 로그는 재생하지 못합니다.
상점/골드/전투 규칙과 카드 능력치는 변경하지 않았습니다.
