아르카나 카드 듀얼 v1.1.0 — AI 2.0 고급 적응형 심리전

기준: v1.0.10 누적 패치가 적용된 arcana_card_duel 프로젝트

[적용 방법]
1. 기존 arcana_card_duel 폴더를 백업합니다.
2. 이 ZIP을 게임 폴더의 바로 상위 위치에 풉니다.
3. 동일 이름 파일을 덮어씁니다. (기존 이미지/음성/카드팩 그대로 보존)
4. arcana_card_duel/index.html을 열어 게임을 실행합니다.

[패치 파일]
arcana_card_duel/index.html (AI 스크립트 연결 / 내부 스펠 AI 호출 허용)
arcana_card_duel/ai2.js (신규)
arcana_card_duel/fast_balance.js (숫자 전술 AI 선택 가능)
arcana_card_duel/fast_balance.html (AI 비교 선택 UI)
arcana_card_duel/fast_balance_ui.js (AI 선택 전달)

[AI 2.0 실제 게임 기능]
- 소환 후보 점수화: 역할, 보유 아군, 상대 전장, 챔피언 시너지, 위험도 평가
- 공격 예약: 전열→후열 순서에 따라 목표의 예상 잔여 체력을 추적,
  앞선 공격에서 사망할 대상을 뒤의 공격자가 가능하면 피하도록 함
- 키레네/카스토리스/죽음의 용/MK.1/샤먼/오두막의 특수 가치 반영
- 마법 후보별 예상 효과 평가: 처치, 피해, 보호막, 회복, 각성 지원, 상태 이상
- 공정한 행동 관찰: 상대 비공개 손패/덱 순서/미래 난수/향후 행동을 읽지 않음
- 공개된 소환/확정 공격 예약/발동된 마법을 기록하며 이번 대전 안에서 학습
- 성격: 적응형(기본), 계산형, 공격형, 수비형, 교란형
- 난이도: 어려움(기본), 전문가
- 개발자 측면 패널: 이미 확정된 AI의 선택과 점수, 대체 후보를 확인 가능
- 상대 턴 진행 도중 판단 기록은 공개하지 않음
- 기존 전투 수치, 카드 ID, 일러스트, 음성은 변경하지 않음

[숫자 시뮬레이터]
- 덱 A와 덱 B에 각각 적응형 AI 2.0 또는 기존 AI를 지정 가능
- 두 AI 모두 2.0으로 놓으면 카드 밸런스 비교에 적합
- 서로 다르게 놓으면 판단 개선 평가의 근사 실험에 활용 가능
- 숫자 엔진의 AI 2.0은 소환/공격 예약 중심의 경량 전술 AI로,
  브라우저 게임의 장기 행동 학습까지 완전히 재현하지는 않음
- 양쪽 시뮬 판정기는 동일하며 일부 UI 전투 예외가 다를 수 있음

[테스트]
- 인라인 Chromium 평가: 게임 스크립트 25개 순차 로딩, JS 예외 0
- 공격 예약 실험: 체력 2 적을 선공이 제거할 때 다음 공격은 다른 적을 선택
- 마법 발동: 전투 중 화면 잠금 상태에서도 AI 스펠 사용 및 잠금 복원
- 일반 한 턴 전체 흐름 정상 종료 (게임 시작 → AI 턴 → 플레이어 다음 턴)
- 숫자 엔진: 3,000판 테스트 / 선후공 교대
