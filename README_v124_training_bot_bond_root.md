# 아르카나 카드 듀얼 v1.2.4 — 실버 증강 세부 규칙 패치

기준: v1.2.3 실버 증강 20종 통합판. 기존 1대1 모드는 그대로 유지. 이번 패치가 변경하는 증강은 `뿌리 박기`, `인연`, `탑`, `훈련봇 변환`이며 실버 20장 원본 일러스트는 그대로 보존합니다.

## 설치
- `arcana_card_duel` 폴더가 들어 있는 **상위 폴더**에 v1.2.4 패치 ZIP 압축을 풀고 덮어쓰기.
- 또는 v1.2.4 전체 통합본 압축을 풀어 `arcana_card_duel/index.html` 실행.
- 새 증강 선택을 시험하려면 **새 8인 리그**를 시작합니다. 기존 1대1 모드 카드 밸런스는 바뀌지 않습니다.

## 이번 패치 상세 규칙

### 뿌리 박기
- 매 **8인 리그 전투 라운드**에 아군 전열의 `3번` 또는 `4번` 중 **딱 한 칸**을 자동으로 지정합니다.
- 지정 위치는 라운드마다 달라질 수 있습니다. 같은 경기 동안에는 고정됩니다. 게임 상단에 선택된 번호를 표기합니다.
- 지정 칸에 놓인 아군 유닛만 공격력 +2, 최대/현재 체력 +2, 흡수(흡혈) 효과를 얻습니다. **후열 3/4번은 적용되지 않습니다.**
- 유닛이 다른 칸으로 이동하면 효과를 잃고, 새 유닛이 지정 칸에 들어오면 효과를 받습니다.
- AI 수치 엔진과 화면 전투의 칸 판정이 일치합니다.

### 인연
- 자기 후열 1번과 전열 6번의 유닛이 동시에 존재하면 자동 연결됩니다.
- 두 유닛의 **현재 HP를 합산한 하나의 공유 HP**, 두 유닛의 **최대 HP를 합산한 공유 최대 HP**를 갖습니다. 각 카드에 동일한 공동 체력 수치가 보입니다.
- 어느 쪽이 맞더라도 공유 HP에서 **실제 피해량 한 번만** 차감합니다. 어느 쪽이 회복하더라도 공유 HP에 **실제 회복량 한 번만** 합산합니다.
- 공유 HP가 0 이하가 되면 두 유닛 모두 사망합니다.
- **임시 세부 규칙**: 위치 교환 등으로 연결이 끊기면 남은 공유 HP를 원래 두 유닛의 최대 체력 비율대로 분배(반올림 처리), 각 유닛의 일반 HP로 복원합니다. 다시 양끝 칸으로 배치되면 새 합산 HP로 연결됩니다. 사용자가 별도로 확정하지 않은 예외 상황을 처리하기 위한 규칙입니다.

### 표적 훈련봇 — 공통
- 새로 제공한 `아카데미의 표적 훈련 로봇(1).png` 일러스트를 적용합니다. 원본 PNG를 `silver_augments/training_bot.png`로 보존하고 경량 WebP를 게임 카드에 사용합니다.
- `탑` 훈련봇과 `훈련봇 변환` 훈련봇 모두 기본 공격력 0, 공격 대상 지정 불가, 장비 장착 불가.
- `훈련봇 변환`으로 생성된 봇의 체력은 흡수한 **현재 유닛 체력 합계**를 사용하고, **반사 피해는 없습니다**(탑 전용).

### 탑의 스테이지별 훈련봇
| 스테이지 | 체력 | 피격 시 반사 피해 |
|---|---:|---:|
| 1 | 4 | 1 |
| 2 | 6 | 1 |
| 3 | 8 | 2 |
| 4 | 12 | 2 |
| 5 | 12 | 3 |
| 6 | 16 | 3 |
| 7 이상 | 20 | 4 |

- `탑` 보유자는 AI 포함 매 1대1 리그 전투가 시작될 때 훈련봇 카드 1장을 손패로 얻습니다.
- 훈련봇이 직접 피해를 받으면 해당 공격자에게 표의 반사 피해를 1회 줍니다. 마법처럼 공격 유닛이 없는 피해는 반사 대상을 지정하지 않습니다.
- 리그 스테이지가 바뀌면 새 전투에서 새 단계의 훈련봇을 받습니다. **이미 진행 중인 1대1 전투의 훈련봇 체력은 중간에 변하지 않습니다.**
