# 아르카나 카드 듀얼 v1.2.5 (웹 최적화)

HTML/JavaScript 정적 웹 게임입니다. **1대1 대전**, **8인 리그**, **실버 증강 20종**, 수치 밸런스 시뮬레이터와 캐릭터 일러스트를 유지합니다.

## 실행

- `index.html`: 1대1 게임과 8인 리그
- `fast_balance.html`: 저사양 수치 밸런스 테스트
- GitHub Pages: https://jarh0907-ui.github.io/arcana_card_duel/

## v1.2.5 최적화

- 캐릭터 녹음 음성 WAV 파일 13개와 재생 기능 제거. **전투 합성 효과음 유지**.
- 기존 PNG 리소스를 같은 종횡비의 WebP로 변환. 게임 일러스트의 크기나 카드 비율을 강제로 변경하지 않음.
- 카드 및 리그 이미지에 지연 로딩/비동기 디코딩 사용.
- 이전 웹 배포본에서 0바이트였던 `luck_thumb.webp` 썸네일 재생성.
- 오래된 캐릭터 음성 클릭 호출 제거: 카드 선택 시 JS 오류 방지.
- GitHub Pages용 `.nojekyll` 포함.

게임 로직 자체의 공격력/체력/증강 규칙은 변경하지 않았습니다. 이전의 1.2.4 게임 내용을 기반으로 제작되었습니다.
자세한 리그 및 실버 증강 규칙은 `README_v120_8인리그.txt`, `README_v123_silver.md`, `README_v124_training_bot_bond_root.md`를 참고하세요.

## 주의

- 소스 파일을 직접 수정했다면 배포 전에 별도로 백업해 두세요.
- 포함된 캐릭터 이미지의 공개 배포 권한은 별도 확인이 필요합니다.
