# 아르카나 카드 듀얼 WEB v1.2.6

GitHub Pages에서 실행하는 턴제 카드 대전 게임입니다. 기존 **1대1 대전**, **8인 생존 리그**, **AI 숫자 시뮬레이터**, 개발자 테스트 기능을 유지합니다.

## 실행
- 웹사이트: https://jarh0907-ui.github.io/arcana_card_duel/
- 로컬: `index.html`을 엽니다. (`fast_balance.html`은 경량 숫자 밸런스 테스트 도구)
- GitHub Pages는 `main` 브랜치의 `/(root)`를 배포합니다.

## 8인 리그 및 증강
- 8인 리그는 스테이지당 전투 5회와 상점 2회, 매 스테이지 7라운드로 진행합니다.
- **1-1, 1-2**는 증강 없이 진행합니다. **1-3 전투 시작 전** 플레이어가 실버 증강을 선택하며, AI 7명도 그때 선택합니다.
- 실버 증강 **총 31종**: 기존 20종 + 신규 11종.
- **약간 신비한 주사위**: 선택 순간 1~6 중 하나를 같은 확률로 굴려 각각 `2 / 4 / 7 / 10 / 13 / 17`골드를 한 번 받습니다.
- **탐사**: 매 전투 자기 턴 시작에 후열 맨 오른쪽 유닛을 희생하고 마나 비용을 누적합니다. **33마나 보상은 추후 확정**되며, 현재 보상 지급은 보류합니다.
- **새로 고침의 날**: 원하는 손패를 직접 선택해 교체합니다. 사용 횟수는 3회입니다.
- **권투 교습**: 전열 유닛에게만 전열 유닛 2장당 체력 +1이 적용됩니다.
- 캐릭터 녹음 음성 WAV는 제거되었으며, 전투 합성 효과음은 유지됩니다.

## 데이터 및 이미지
- `silver_augments.js`: 실버 증강과 시각 전투의 실버 효과
- `league_v114.js`: 리그 진행, 상점·골드·전투 정산, 증강 선택 시점
- `fast_balance.js`: AI 숫자 전투 및 증강 효과
- `캐릭터/`: 게임 캐릭터 이미지와 설정
- `silver_augments/`: 선택 화면용 `_thumb.webp` 및 원본 해상도 WebP
- `assets-manifest.json`: 정적 이미지 목록

기존 1대1 규칙은 유지됩니다. 8인 리그 저장 공간은 v1.2.6 전용으로 분리되어, 이전 버전의 저장 데이터가 덮어써지지 않습니다.
