# 아르카나 카드 듀얼 v1.2.0

인터넷 없이 HTML/JavaScript로 실행 가능한 턴제 1대1 카드 전투 및 8인 경쟁 리그.

## 시작
- `index.html`을 열면 기존 **1대1 모드**가 실행됩니다.
- 상단의 **🏆 8인 리그** 버튼으로 새로운 경쟁 모드를 시작합니다.
- `fast_balance.html`은 기존 저사양 숫자 밸런스 실험 도구입니다.

## 8인 리그
8명, 글로벌 HP 100, 스테이지당 7라운드(전투·전투·전투·상점·전투·전투·상점).
전투/상점, 골드/이자/연승/연패, 구매/제거/강화/팀 버프, AI 대전 기록 관전을 지원합니다.
상점 가격 및 강화 수치는 **임시값**이며 증강체는 아직 구현하지 않았습니다.
자세한 규칙: `README_v120_8인리그.txt`.

## 데이터 구성
- `캐릭터/`: 기존 키레네, 카스토리스, 츄츄족 및 머신 등 캐릭터 이미지·음성·설정.
- `ai2.js`: 기존 적응형 전투 AI.
- `lane_v112.js`: 기존 6라인 공격 및 공격/수비 재배치.
- `fast_balance.js`: 숫자 전투 및 AI 관전 상태 기록.
- `league_v114.js`: 8인 리그 상태, 골드, 상점, 순위, 경량 관전.

※ 일반 1대1과 8인 리그는 별개입니다. 게임 데이터를 수정하는 개발자 테스트 버튼은 1대1에서 사용하세요.
